Partituras Uploader

Sheet music arrangements by Gabriel Altali, for piano, solo instruments with piano, and duets.

Partituras Uploader is a small private desktop tool that uploads demonstration videos of these arrangements to the arranger's own channel on ▶ YouTube, using the YouTube API Services. Each video links to the store page where the sheet music can be bought.

The tool has no other users and is not offered to the public.
