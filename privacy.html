Privacy Policy – Partituras Uploader

Last updated: November 19, 2026

Partituras Uploader is a private desktop tool used only by its owner, the arranger Gabriel Altali, to upload demonstration videos of his own sheet music arrangements to his own YouTube channel.

Use of YouTube API Services

Partituras Uploader uses the YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Information accessed through the YouTube API Services is also subject to the Google Privacy Policy.

Data accessed

With the owner's authorization (OAuth 2.0, scopes youtube.upload and youtube.force-ssl), the tool: uploads videos, sets their thumbnails, posts one comment on each uploaded video and reads the basic information of the authorized channel to confirm which channel is connected. It does not read viewers' data, comments of other people, analytics or any other account.

Data stored and retention

The OAuth token is stored only on the owner's computer, in a file outside any shared folder. The tool keeps a local record of the IDs and links of the videos it uploaded, so that the same video is not uploaded twice. No data is stored on any server. The tool does not collect, store or share personal data of any other person, and it has no other users.

Sharing

No data is sold or shared with third parties.

Deleting data and revoking access

Access can be revoked at any time on the Google security settings page (myaccount.google.com/permissions). Deleting the token file and the local record removes all data the tool keeps. Videos uploaded to the channel can be deleted in YouTube Studio. Requests about this policy: altalibrocchine@gmail.com.
